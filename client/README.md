# Contest client

React/Vite frontend for creator signup, role-switching login, residency updates, media posts, feed engagement, and the admin winner/KYC dashboard.

Set `VITE_USER_SERVICE_URL` and `VITE_ADMIN_SERVICE_URL` in the client environment, then run:

```powershell
npm.cmd run dev
```

Use `npm.cmd run build` for a production build.
